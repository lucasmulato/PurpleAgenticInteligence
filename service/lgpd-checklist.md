# Checklist LGPD (curto)

Durante a auditoria:

1. Coletar só o necessário para o inventário de ações.
2. Registrar fonte e data de cada informação usada.
3. Não copiar credenciais, tokens ou dados pessoais para o relatório.
4. Reduzir ou anonimizar exemplos de prompts e respostas.
5. Definir quem pode ver o relatório e por quanto tempo ele fica guardado.
6. Respeitar recusa de contato imediatamente e registrar o opt-out.
7. Não usar dados de prospects para treinar modelo algum.
8. **Revisar este checklist com advogado antes de usar em cliente.**

Este serviço não garante conformidade com a LGPD. Ele produz evidências e
limita a exposição de dados.
