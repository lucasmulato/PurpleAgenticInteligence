## 🧪 Core Research Pillars (2026 Focus)

### 1. Asynchronous Monitoring (The "Async Shield")
Inspired by *arXiv:2512.13526 (UK AISI)*, PIA utilizes **Shadow Evaluation**.
* **Concept:** Instead of blocking prompts in real-time (high latency), PIA monitors agent trajectories **asynchronously**.
* **Action:** It audits the "execution log" 500ms post-action. If a breach signature is detected, it triggers a session rollback and a policy rewrite.

### 2. The Pareto Frontier of Safety
We evaluate every autonomous patch against the **Lobotomy Index**.
* **Security ($S$):** Resistance to the latest evolved attack vector.
* **Utility ($U$):** Maintenance of agent performance on "Golden Baseline" tasks.
* **Goal:** Reach a **Nash Equilibrium** where the cost to the attacker exceeds the reward, without degrading user experience.

$$S_{optimal} = \max(S) \text{ subject to } U \geq U_{baseline} - \epsilon$$

### 3. Automated Remediation (Self-Patching)
PIA doesn't just alert; it **heals**.
- **Input:** Successful Red Team breach log.
- **Output:** A validated, unit-tested PR that updates the `security_manifest.json` and adjusts the model's system-level constraints.
